# ProFocus

Personal planner (Vite + React 18 + TypeScript, no backend). Read `.claude/skills/profocus/SKILL.md` before changing code: it maps the codebase and the workflow.

## Commands

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest
npm run typecheck
npm run build
```

Before committing: `npm run typecheck && npm test && npm run build` must pass.

Curated ECC skills, agents and rules live in `.claude/` (see `.claude/ECC.md`).
